## Production Checklist

Before deploying to production, ensure:

- [ ] Environment variables configured
- [ ] Database migrations applied
- [ ] Error monitoring setup (Sentry)
- [ ] Logging configured (Better Stack)
- [ ] Uptime monitoring enabled (Checkly)
- [ ] Analytics installed (PostHog)
- [ ] Security headers configured
- [ ] Rate limiting enabled
- [ ] SSL/TLS certificates valid
- [ ] Backup strategy in place
- [ ] Rollback plan documented
- [ ] On-call rotation defined

## Deployment

### Production Deployment

```bash
# 1. Run tests
pnpm ci:full

# 2. Build
pnpm build

# 3. Apply migrations
pnpm --filter web db:migrate

# 4. Deploy
vercel --prod
```

### Rollback

```bash
# Revert to previous deployment
vercel rollback

# Or rollback database
./apps/web/scripts/db/rollback.sh
```

## Monitoring Stack

### Error Tracking (Sentry)

```typescript
// Automatic error capture
import * as Sentry from '@sentry/nextjs'

Sentry.captureException(error)
```

**Dashboard:** https://sentry.io

### Uptime Monitoring (Checkly)

```typescript
// Synthetic monitoring
test('API is reachable', async () => {
  const response = await fetch('https://api.yourapp.com/health')
  expect(response.ok).toBe(true)
})
```

**Dashboard:** https://checklyhq.com

### Analytics (PostHog)

```typescript
// Track custom events
posthog.capture('user_signed_up', {
  plan: 'pro',
})
```

**Dashboard:** https://app.posthog.com

## Logging

### Structured Logging

```typescript
import { logger } from '@/libs/Logger'

logger.info('User created', {
  userId: user.id,
  email: user.email,
})

logger.error('Payment failed', {
  error,
  userId,
  amount,
})
```

### Log Levels

- **debug** - Development debugging
- **info** - General information
- **warn** - Warnings, potential issues
- **error** - Errors, exceptions
- **fatal** - Critical failures

### Better Stack Integration

Logs automatically shipped to Better Stack in production.

**Dashboard:** https://logs.betterstack.com
