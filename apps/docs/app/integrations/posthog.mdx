# PostHog

Open-source product analytics, feature flags, and session replay platform.

## Overview

PostHog provides comprehensive product analytics with:

- **Event Tracking** - Custom events, pageviews, autocapture
- **User Identification** - Track users across sessions
- **Feature Flags** - A/B testing, gradual rollouts
- **Session Replay** - Watch user sessions
- **Funnels** - Conversion analysis
- **Cohorts** - User segmentation
- **Dashboards** - Custom metrics and KPIs

## Quick Setup

### 1. Get PostHog API Key

Sign up at [posthog.com](https://posthog.com) or self-host:

1. Create a new project
2. Copy your **Project API Key** (starts with `phc_`)
3. Note your **Host URL** (default: `https://app.posthog.com`)

### 2. Configure Environment Variables

```bash
# apps/web/.env.local

NEXT_PUBLIC_POSTHOG_KEY=phc_your_project_api_key_here
NEXT_PUBLIC_POSTHOG_HOST=https://app.posthog.com
```

### 3. Test Configuration

```bash
# Development mode
pnpm --filter web dev

# Visit any page - pageview should be tracked
# Check PostHog dashboard: Activity → Live Events
```

## Configuration

The boilerplate includes pre-configured PostHog setup:

### `libs/PostHog.tsx`

PostHog provider component:

```typescript
'use client'

import { useEffect } from 'react'
import { usePathname, useSearchParams } from 'next/navigation'
import posthog from 'posthog-js'
import { PostHogProvider } from 'posthog-js/react'

if (typeof window !== 'undefined') {
  posthog.init(process.env.NEXT_PUBLIC_POSTHOG_KEY!, {
    api_host: process.env.NEXT_PUBLIC_POSTHOG_HOST,
    person_profiles: 'identified_only',
    capture_pageview: false, // Manual pageview tracking
    capture_pageleave: true,
    session_recording: {
      maskAllInputs: true,
      maskTextSelector: '*',
    },
  })
}

export function PHProvider({ children }: { children: React.ReactNode }) {
  return <PostHogProvider client={posthog}>{children}</PostHogProvider>
}
```

### `components/PostHogPageView.tsx`

Automatic pageview tracking:

```typescript
'use client'

import { useEffect } from 'react'
import { usePathname, useSearchParams } from 'next/navigation'
import { usePostHog } from 'posthog-js/react'

export default function PostHogPageView() {
  const pathname = usePathname()
  const searchParams = useSearchParams()
  const posthog = usePostHog()

  useEffect(() => {
    if (pathname && posthog) {
      let url = window.origin + pathname
      if (searchParams?.toString()) {
        url = `${url}?${searchParams.toString()}`
      }
      posthog.capture('$pageview', {
        $current_url: url,
      })
    }
  }, [pathname, searchParams, posthog])

  return null
}
```

### Identify Users

```typescript
'use client'

import { useEffect } from 'react'
import { usePostHog } from 'posthog-js/react'

export function AuthProvider({ user, children }) {
  const posthog = usePostHog()

  useEffect(() => {
    if (user) {
      // Identify user
      posthog.identify(user.id, {
        email: user.email,
        name: user.name,
        plan: user.plan,
        signup_date: user.createdAt,
      })
    } else {
      // Reset on logout
      posthog.reset()
    }
  }, [user, posthog])

  return <>{children}</>
}
```

## Feature Flags

### Check Feature Flags

```typescript
'use client'

import { usePostHog } from 'posthog-js/react'
import { useEffect, useState } from 'react'

export function NewFeature() {
  const posthog = usePostHog()
  const [showFeature, setShowFeature] = useState(false)

  useEffect(() => {
    const flag = posthog.isFeatureEnabled('new-dashboard')
    setShowFeature(flag)
  }, [posthog])

  if (!showFeature) return null

  return <NewDashboard />
}
```

### Feature Flag with Variants

```typescript
'use client'

import { useFeatureFlagVariantKey } from 'posthog-js/react'

export function PricingPage() {
  const variant = useFeatureFlagVariantKey('pricing-test')

  return (
    <>
      {variant === 'control' && <OldPricing />}
      {variant === 'variant-a' && <NewPricingA />}
      {variant === 'variant-b' && <NewPricingB />}
    </>
  )
}
```

### Server-Side Feature Flags

```typescript
// app/dashboard/page.tsx
import { PostHog } from 'posthog-node'

const posthog = new PostHog(process.env.NEXT_PUBLIC_POSTHOG_KEY!, {
  host: process.env.NEXT_PUBLIC_POSTHOG_HOST,
})

export default async function DashboardPage() {
  const user = await getCurrentUser()

  const showNewDashboard = await posthog.isFeatureEnabled(
    'new-dashboard',
    user.id
  )

  return showNewDashboard ? <NewDashboard /> : <OldDashboard />
}
```

export function ConditionalRecording({ user }) {
  const posthog = usePostHog()

  useEffect(() => {

## A/B Testing

### Setup A/B Test

1. **Create Feature Flag in PostHog:**
   - Name: `pricing-test`
   - Variants: `control`, `variant-a`, `variant-b`
   - Rollout: 33% each

2. **Implement in Code:**

```typescript
'use client'

import { usePostHog } from 'posthog-js/react'
import { useEffect, useState } from 'react'

export function PricingTest() {
  const posthog = usePostHog()
  const [variant, setVariant] = useState<string>('control')

  useEffect(() => {
    const flag = posthog.getFeatureFlagVariant('pricing-test')
    setVariant(flag as string)
  }, [posthog])

  const handlePurchase = () => {
    posthog.capture('purchase_completed', {
      test_variant: variant,
      price: variant === 'variant-a' ? 99 : 149,
    })
  }

  return (
    <>
      {variant === 'control' && <Pricing price={129} />}
      {variant === 'variant-a' && <Pricing price={99} />}
      {variant === 'variant-b' && <Pricing price={149} />}
    </>
  )
}
```

3. **Analyze Results:**
   - PostHog Dashboard → Experiments
   - Compare conversion rates by variant

## Server-Side Tracking

### API Routes

```typescript
// app/api/checkout/route.ts
import { PostHog } from 'posthog-node'

const posthog = new PostHog(
  process.env.NEXT_PUBLIC_POSTHOG_KEY!,
  { host: process.env.NEXT_PUBLIC_POSTHOG_HOST }
)

export async function POST(request: Request) {
  const { userId, items } = await request.json()

  // Track server-side event
  posthog.capture({
    distinctId: userId,
    event: 'server_checkout_completed',
    properties: {
      items,
      source: 'api',
    },
  })

  await posthog.shutdown() // Important: flush events

  return Response.json({ success: true })
}
```

### Background Jobs

```typescript
import { PostHog } from 'posthog-node'

const posthog = new PostHog(
  process.env.NEXT_PUBLIC_POSTHOG_KEY!,
  { host: process.env.NEXT_PUBLIC_POSTHOG_HOST }
)

export async function processSubscriptionRenewal(userId: string) {
  // Process renewal
  await renewSubscription(userId)

  // Track event
  posthog.capture({
    distinctId: userId,
    event: 'subscription_renewed',
    properties: {
      renewal_type: 'automatic',
      processed_at: new Date().toISOString(),
    },
  })

  await posthog.shutdown()
}
```

## Privacy & GDPR

### Respect User Consent

```typescript
'use client'

import { usePostHog } from 'posthog-js/react'
import { useEffect } from 'react'

export function ConsentManager({ hasConsent }) {
  const posthog = usePostHog()

  useEffect(() => {
    if (hasConsent) {
      posthog.opt_in_capturing()
    } else {
      posthog.opt_out_capturing()
    }
  }, [hasConsent, posthog])

  return null
}
```

### Anonymize Users

```typescript
// Don't identify users, use anonymous tracking
posthog.capture('button_clicked', {
  button_name: 'signup',
  // No user email or name
})
```

## Best Practices

✅ **DO:**

- Identify users after authentication
- Use descriptive event names (`user_signed_up` not `event1`)
- Include relevant context in event properties
- Reset PostHog on logout
- Use feature flags for gradual rollouts
- Track both success and failure events
- Set up privacy controls (mask sensitive data)
- Use server-side tracking for critical events

❌ **DON'T:**

- Track PII without consent
- Send passwords or tokens
- Use overly generic event names
- Track everything (be selective)
- Forget to call `posthog.shutdown()` on server
- Leave feature flags enabled indefinitely
- Skip GDPR compliance
- Mix client and server-side user IDs

## Troubleshooting

### Events Not Appearing

1. **Check API key:**
   ```bash
   echo $NEXT_PUBLIC_POSTHOG_KEY
   ```

2. **Verify initialization:**
   - Check browser console for PostHog logs
   - Look for "PostHog initialized" message

3. **Check network tab:**
   - Look for requests to PostHog
   - Verify they're not blocked by ad blockers

4. **Test manually:**
   ```typescript
   posthog.capture('test_event', { test: true })
   ```

### Feature Flags Not Working

1. **Verify user is identified:**
   ```typescript
   posthog.identify('user-123')
   ```

2. **Check flag configuration:**
   - PostHog Dashboard → Feature Flags
   - Verify rollout percentage

3. **Force reload flags:**
   ```typescript
   await posthog.reloadFeatureFlags()
   ```

### Session Replay Not Recording

1. **Check recording is enabled:**
   ```typescript
   posthog.sessionRecordingStarted()  // Should return true
   ```

2. **Verify configuration:**
   ```typescript
   session_recording: {
     maskAllInputs: true,
   }
   ```

3. **Check browser compatibility:**
   - Session replay requires modern browsers
   - Not supported in incognito mode (some browsers)

### Server-Side Events Missing

1. **Verify shutdown is called:**
   ```typescript
   await posthog.shutdown()  // Flushes events
   ```

2. **Check API key:**
   ```typescript
   // Should be same key as client
   const posthog = new PostHog(process.env.NEXT_PUBLIC_POSTHOG_KEY!)
   ```

## Cost Optimization

### Free Tier Limits

- **1 million events/month**
- **5,000 session replays/month**
- **Unlimited feature flags**
- **1 year data retention**

### Reduce Costs

1. **Sample high-volume events:**
   ```typescript
   // Only track 10% of pageviews
   if (Math.random() < 0.1) {
     posthog.capture('$pageview')
   }
   ```

2. **Limit session replays:**
   ```typescript
   session_recording: {
     sampleRate: 0.1,  // Record 10% of sessions
   }
   ```

3. **Use selective tracking:**
   ```typescript
   // Only track critical events
   posthog.capture('purchase_completed')  // ✅
   // Skip trivial events
   // posthog.capture('mouse_moved')  // ❌
   ```

4. **Manage retention:**
   - PostHog Settings → Data Management
   - Reduce retention for old data
