# Testing

Comprehensive testing strategy with unit, integration, and E2E tests.

## Testing Stack

- **Vitest** - Unit and integration testing
- **Playwright** - End-to-end testing
- **Storybook** - Component testing and documentation
- **Checkly** - Synthetic monitoring in production

## Quick Start

```bash
# Unit tests
pnpm test

# E2E tests (install browsers first)
npx playwright install
pnpm test:e2e

# Storybook
pnpm --filter web storybook

# Integration tests
pnpm --filter web test:integration
```

## Testing Layers

### Unit Tests (Vitest)

**Fast, focused tests for individual units:**

```typescript
// Component.test.tsx
import { render, screen } from '@testing-library/react'
import { Button } from './Button'

describe('Button', () => {
  it('renders with text', () => {
    render(<Button>Click me</Button>)
    expect(screen.getByText('Click me')).toBeInTheDocument()
  })

  it('calls onClick when clicked', () => {
    const onClick = vi.fn()
    render(<Button onClick={onClick}>Click</Button>)

    screen.getByText('Click').click()
    expect(onClick).toHaveBeenCalledOnce()
  })
})
```

**Location:** Colocated with source (`*.test.ts`, `*.test.tsx`)

[Learn more →](/guides/testing/unit)

### Integration Tests (Vitest)

**Test multiple units working together:**

```typescript
// api.spec.ts
describe('User API', () => {
  it('creates user and returns 201', async () => {
    const response = await fetch('/api/users', {
      method: 'POST',
      body: JSON.stringify({ email: 'test@example.com' })
    })

    expect(response.status).toBe(201)
    const user = await response.json()
    expect(user.email).toBe('test@example.com')
  })
})
```

**Location:** `tests/integration/`

[Learn more →](/guides/testing/integration)

### E2E Tests (Playwright)

**Full user flows in real browser:**

```typescript
// auth.e2e.ts
import { test, expect } from '@playwright/test'

test('user can sign in', async ({ page }) => {
  await page.goto('/sign-in')

  await page.fill('[name="email"]', 'user@example.com')
  await page.fill('[name="password"]', 'password')
  await page.click('button[type="submit"]')

  await expect(page).toHaveURL('/dashboard')
  await expect(page.locator('text=Welcome')).toBeVisible()
})
```

**Location:** `tests/e2e/`

[Learn more →](/guides/testing/e2e)

### Storybook

**Visual component testing:**

## When to Use Each Type

| Test Type | When to Use | Speed | Coverage |
|-----------|-------------|-------|----------|
| Unit | Individual functions, components | ⚡ Fast | Low |
| Integration | API routes, database operations | ✅ Medium | Medium |
| E2E | Critical user flows, authentication | 🐌 Slow | High |
| Storybook | UI components, design system | ⚡ Fast | Visual |

## Testing Strategy

### Test Pyramid

```
        ┌────────┐
        │  E2E   │  Few, critical flows
        ├────────┤
        │  Integ │  API, database, services
        ├────────┤
        │  Unit  │  Most tests here
        └────────┘
```

### What to Test

✅ **DO Test:**
- Business logic
- API endpoints
- Database operations
- Authentication flows
- Critical user journeys
- Edge cases and errors

❌ **DON'T Test:**
- Third-party libraries
- Framework internals
- Trivial getters/setters
- UI implementation details

## Coverage

### Generate Coverage Report

```bash
pnpm test:coverage
```

Opens HTML report in `coverage/index.html`

### Coverage Goals

- **Unit tests:** >80% coverage
- **Integration tests:** Critical paths covered
- **E2E tests:** Happy paths + edge cases

## Best Practices

✅ **DO:**
- Write tests before fixing bugs (TDD)
- Test behavior, not implementation
- Use descriptive test names
- Isolate tests (no shared state)
- Mock external dependencies
- Clean up after tests

❌ **DON'T:**
- Test implementation details
- Share state between tests
- Skip flaky tests (fix them!)
- Test everything (focus on critical paths)
- Ignore failing tests

## Continuous Integration

### GitHub Actions

```yaml
# .github/workflows/test.yml
name: Tests
on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
      - run: pnpm install
      - run: pnpm test
      - run: pnpm test:e2e
```

### Pre-commit Hooks

```yaml
# lefthook.yml
pre-commit:
  commands:
    tests:
      run: pnpm test --run
```
